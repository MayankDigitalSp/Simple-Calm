# Still — Meditation Timer

A small, offline Android meditation app with:

- 5, 10, 15, and 20-minute sessions
- Start, pause, resume, and reset controls
- Daily streak tracking
- Total mindful minutes and completed-session counters
- Persistent local stats (no account or internet needed)

## Build the APK with GitHub

1. Upload this project to a GitHub repository.
2. Open **Actions** and select **Build Still APK**.
3. Click **Run workflow** (or push to `main`).
4. Open the completed run and download the **Still-APK** artifact.
5. Unzip it, transfer `app-debug.apk` to your Android phone, and install it.

Android may ask you to allow installation from your browser or file manager.
